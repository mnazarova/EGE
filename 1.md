## 🎯 1. Теоретический минимум

Для успешного решения задачи программным методом необходимо знать, как логические связки из текста КИМ записываются на языке **Python**.

| Операция | Обозначение в КИМ | Синтаксис в Python | Приоритет (от высшего к низшему) |
| :--- | :---: | :---: | :---: |
| **Инверсия (НЕ)** | \(¬x\) / \(\bar{x}\) | `not x` | 1 (Высший) |
| **Конъюнкция (И)** | \(x \wedge y\) / \(x \cdot y\) | `x and y` | 2 |
| **Дизъюнкция (ИЛИ)** | \(x \vee y\) / \(x + y\) | `x or y` | 3 |
| **Импликация (Следование)** | \(x \to y\) | `x <= y` | 4 |
| **Эквивалентность (Тождество)** | \(x \equiv y\) / \(x \leftrightarrow y\) | `x == y` | 5 (Низший) |

## 💻 2. Универсальный шаблон кода

Этот скрипт перебирает все возможные комбинации булевых переменных (\(0\) и \(1\)) и выводит на экран только те строки, которые соответствуют условию задачи.

```python
# Выводим заголовки столбцов в алфавитном порядке
print("x y z w | F")

# Запускаем вложенные циклы для перебора всех вариантов
for x in (0, 1):
    for y in (0, 1):
        for z in (0, 1):
            for w in (0, 1):
                
                # ЗАПИСЬ ВЫРАЖЕНИЯ (Обязательно изолируйте скобками каждую связку!)
                # Пример: (x -> y) /\ (y -> z) /\ (¬z \/ w)
                F = (x <= y) and (y <= z) and ((not z) or w)
                
                # ФИЛЬТР ВЫВОДА:
                # Если в таблице КИМ в столбце F указаны единицы — пишем F == 1
                # Если в таблице КИМ указаны нули — меняем на F == 0
                if F == 1:
                    print(f"{x} {y} {z} {w} | {int(F)}")
```

3. **Метод исключения:** Заполняйте пустые ячейки в КИМ карандашом на основе вывода программы. Как только закроются две переменные, остальные встанут на свои места автоматически.
